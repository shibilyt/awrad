# Dalail al-Khayrat Source Notes

The bundled `dalail-al-khayrat` seed is Arabic-only. Do not import modern
translations, transliteration, commentary, typography, or audio unless that
specific source has a clear reusable license.

Source posture:

- Core work: Imam Muhammad ibn Sulayman al-Jazuli's `Dalail al-Khayrat`, a
  public-domain devotional text.
- Public-domain scan reference:
  https://archive.org/details/Library.mmn_201603
- Proofing and daily-part structure reference:
  https://www.dalailalkhayrat.com/
- Secondary Arabic text cross-check:
  https://shamela.org/pdf/42fdae742addd80c320243b3d65a2e08

The app seed uses the common eight-part reading order: Monday last, then Monday
first on Mondays; Tuesday through Sunday each receive one part. Monday first
contains the opening, the Names of Allah, the Names of the Prophet ﷺ, the
intention, and the first hizb. Monday last contains the eighth hizb and the
completion supplication.

Before treating the seed as a final devotional edition, run a human Arabic
proofread against a trusted printed edition.
