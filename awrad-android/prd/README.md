# Awrad - Dhikr Goals Tracker: Product Requirements Document

This folder contains the complete product requirements for **Awrad**, a mobile app for tracking Islamic dhikr (remembrance) goals with audio-assisted counting, prayer-time integration, and Wird (structured reading) support.

The goal of this PRD is to fully specify every feature so that the app can be recreated from scratch on any platform or framework.
