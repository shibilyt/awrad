# 16 - Built-in Content

## Overview

The app ships with pre-loaded content: 13 dhikrs with audio, a benefits/suggested-goals registry, and at least one Wird collection. This content is inserted into the database on first launch and can be updated on app updates.

## Dhikr Benefits Registry

Benefits and suggested goals are mapped by dhikr transliteration. Not all dhikrs have benefits data. Below is the known mapping:

### "La ilaha illallah" (Tahleel)

**Benefits:**
1. **Key to Paradise** - "Whoever dies and he knows that there is no god but Allah shall enter Paradise." (Source: Muslim)
2. **Best of Dhikr** - "The best dhikr is La ilaha illallah." (Source: Tirmidhi)
3. **Removes sins** - "Whoever says La ilaha illallah 100 times a day will have the equivalent of freeing 10 slaves, 100 good deeds recorded, 100 sins erased, and protection from Shaytan." (Source: Abu Dawud 3116)

**Suggested Goals:**
1. Daily 100x (GoalType: DAILY, target: 100)
2. Daily 1,000x (GoalType: DAILY, target: 1000)
3. One-time 70,000x (GoalType: ONE_TIME, target: 70000)

*(Additional benefits entries may exist for other dhikrs - check the DhikrBenefits registry in the codebase for the complete catalog.)*

## Built-in Wird Collections

### Dalail al-Khayrat

- **Slug:** `dalail_al_khayrat`
- **Name (Arabic):** دلائل الخيرات
- **Name (English):** Dalail al-Khayrat
- **Author:** Imam Muhammad al-Jazuli
- **Schedule Type:** WEEKLY_SPLIT (7 sections for 7 days of the week)
- **Sort Order:** 0

**Sections (7):**
Each section is assigned to a day of the week (Monday through Sunday). Section structure:

| Section | Subtitle | Title |
|---------|----------|-------|
| 0 | Monday | Hizbun 1 |
| 1 | Tuesday | Hizbun 2 |
| 2 | Wednesday | Hizbun 3 |
| 3 | Thursday | Hizbun 4 |
| 4 | Friday | Hizbun 5 |
| 5 | Saturday | Hizbun 6 |
| 6 | Sunday | Hizbun 7 |

Each section contains multiple items with:
- Arabic text (Swalath/salutation formulas)
- Optional transliteration
- Optional translation
- Repeat count (typically 1, some items have higher counts)

## Content Initialization Logic

### Requirements

- R-CONTENT-001: On first app launch, insert all 13 built-in dhikrs into the database.
- R-CONTENT-002: Use "insert ignore" semantics - if a dhikr already exists (by transliteration), skip it.
- R-CONTENT-003: On subsequent launches, sync built-in dhikrs:
  - Add any new dhikrs not already in the database
  - Update `audioUrl` for existing dhikrs if changed
  - Update `audioCountPerPlay` for existing dhikrs if changed
  - Update `title` for existing dhikrs if changed
- R-CONTENT-004: Load Wird collections from bundled JSON files.
- R-CONTENT-005: For each collection:
  - If it exists in DB and bundled version is higher: update collection metadata, delete old sections, re-insert sections and items.
  - If it doesn't exist: insert collection, sections, and items.
- R-CONTENT-006: Collections are matched by `slug` (unique identifier).
- R-CONTENT-007: Content initialization runs during onboarding (before the audio library step).

## Content Format (JSON)

Wird collections are stored as JSON files in a bundled assets directory:

```json
{
  "slug": "dalail_al_khayrat",
  "version": 1,
  "nameAr": "دلائل الخيرات",
  "nameEn": "Dalail al-Khayrat",
  "description": "A collection of prayers upon the Prophet...",
  "author": "Imam Muhammad al-Jazuli",
  "scheduleType": "WEEKLY_SPLIT",
  "sortOrder": 0,
  "sections": [
    {
      "sectionIndex": 0,
      "titleAr": "الحزب الأول",
      "titleEn": "Hizbun 1",
      "subtitle": "Monday",
      "items": [
        {
          "itemIndex": 0,
          "arabic": "بِسْمِ اللَّهِ الرَّحْمَنِ الرَّحِيمِ",
          "transliteration": "Bismillahir Rahmanir Raheem",
          "translation": "In the name of Allah, the Most Gracious, the Most Merciful",
          "repeatCount": 1
        }
      ]
    }
  ]
}
```
