# MOD-WIRD — Structured Wird

## User outcome

The user can discover, create, schedule, and read a structured Wird while retaining local reading progress.

## Scope and requirements

Own bundled/custom definition list/detail/create/edit and the part-based reader/session. Bundled Dalail al-Khayrat content and structural identity follow the versioned Wird contract. Reading sessions persist locally and are reachable by reminder/deep link.

See [FEAT-WIRD-001](../features/FEAT-WIRD-001.md).

## Boundaries

The bundled content contract covers content structure, not necessarily persisted-session sync. Notification schedule execution belongs to MOD-PRAYER-REMINDERS.

## Acceptance

The bundled Wird is readable offline; moving parts preserves definition context; content reordering cannot silently change structural identity.
