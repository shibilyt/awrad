# Product module PRDs

These eight module PRDs group related feature PRDs into user-facing capabilities. They are product boundaries, not Gradle modules or package claims. Individual behavior lives in the [feature PRDs](../features/) and implementation constraints in the [TRD](../../trd/TRD.md).

| Module | Scope | Modules PRD |
|---|---|---|
| MOD-SETUP | First-run entry, language, first practice | [Setup](MOD-SETUP.md) |
| MOD-PRACTICE | Goals, counter, progress/history | [Practice](MOD-PRACTICE.md) |
| MOD-DHIKR-LIBRARY | Catalog, custom dhikr, audio, Quran reader | [Dhikr library](MOD-DHIKR-LIBRARY.md) |
| MOD-WIRD | Structured Wird content and reading | [Wird](MOD-WIRD.md) |
| MOD-PRAYER-REMINDERS | Location, prayer context, reminder lifecycle | [Prayer and reminders](MOD-PRAYER-REMINDERS.md) |
| MOD-ACCOUNT-SYNC | Account, session, local-first sync | [Account and sync](MOD-ACCOUNT-SYNC.md) |
| MOD-COMMUNITY | API-backed stats and sample social surfaces | [Community](MOD-COMMUNITY.md) |
| MOD-SETTINGS | Preference and local-data hub | [Settings](MOD-SETTINGS.md) |
