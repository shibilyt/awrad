Variant A

Metrics first

A familiar analytics stack. Best when users want to scan numbers quickly and then explore the chart.

New signals

  • Affinity: an encouraging return-and-consistency signal, not a spiritual score.
  • Time spent: average duration per counted day and per session.
  • Adherence: target met, partial, and missed scheduled days.

Data note

Average time needs persisted session-duration data. The current count history can support totals, dates, targets, streaks, and slot performance, but not reliable elapsed time.
