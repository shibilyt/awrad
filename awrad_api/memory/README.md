# Awrad API — Codebase Master Map

Awrad API is a Phoenix 1.8.5 application that serves the Awrad Android and iOS apps and provides a web interface via Phoenix LiveView. It uses PostgreSQL with Ecto, bcrypt password hashing, JWT access tokens (Joken) for mobile API auth, and session/cookie auth for the web app. Authentication routes are implemented; general mobile data synchronization is not yet an end-to-end contract.

## Module Map

| Module | Purpose | Key Entry Points |
|---|---|---|
| `AwradApi.Accounts` | User registration, login, password management, session/token lifecycle | `lib/awrad_api/accounts.ex` |
| `AwradApi.Accounts.User` | User Ecto schema (email, hashed_password, confirmed_at) | `lib/awrad_api/accounts/user.ex` |
| `AwradApi.Accounts.UserToken` | DB token schema — session, refresh, magic link, change email | `lib/awrad_api/accounts/user_token.ex` |
| `AwradApi.Accounts.Token` | JWT access token signing/verification + refresh token logic | `lib/awrad_api/accounts/token.ex` |
| `AwradApi.Accounts.Scope` | Caller scope struct (wraps current user) | `lib/awrad_api/accounts/scope.ex` |
| `AwradApi.Accounts.UserNotifier` | Email delivery for magic links, email change | `lib/awrad_api/accounts/user_notifier.ex` |
| `AwradApi.Repo` | Ecto Repo (PostgreSQL) | `lib/awrad_api/repo.ex` |
| `AwradApi.Mailer` | Swoosh mailer | `lib/awrad_api/mailer.ex` |

| Web Module | Purpose | Key Entry Points |
|---|---|---|
| `AwradApiWeb.Router` | All routes and pipelines (browser, api, api_auth) | `lib/awrad_api_web/router.ex` |
| `AwradApiWeb.Endpoint` | HTTP entry point (session, parsers, static files) | `lib/awrad_api_web/endpoint.ex` |
| `AwradApiWeb.UserAuth` | Session auth plugs (generated by phx.gen.auth) | `lib/awrad_api_web/user_auth.ex` |
| `AwradApiWeb.Plugs.ApiAuth` | JWT Bearer token plug for API pipeline | `lib/awrad_api_web/plugs/api_auth.ex` |
| `AwradApiWeb.Api.AuthController` | JSON auth endpoints (register, login, refresh, forgot/reset password, logout) | `lib/awrad_api_web/controllers/api/auth_controller.ex` |
| `AwradApiWeb.CoreComponents` | Shared UI components (header, button, input, flash, icon) | `lib/awrad_api_web/components/core_components.ex` |
| `AwradApiWeb.Layouts` | App and root layouts | `lib/awrad_api_web/components/layouts.ex` |

## Project Structure

```
lib/
  awrad_api/                        # Business logic (contexts)
    accounts/                       # Auth domain
      user.ex                       #   User schema
      user_token.ex                 #   DB token schema
      user_notifier.ex              #   Email delivery
      token.ex                      #   JWT + refresh token logic
      scope.ex                      #   Caller scope
    accounts.ex                     # Accounts context (public API)
    application.ex                  # OTP supervisor
    repo.ex                         # Ecto Repo
    mailer.ex                       # Swoosh mailer
  awrad_api_web/                    # Web layer
    plugs/
      api_auth.ex                   #   JWT Bearer auth plug
    controllers/
      api/
        auth_controller.ex          #   JSON auth endpoints
      user_registration_controller.ex
      user_session_controller.ex
      user_settings_controller.ex
      fallback_controller.ex
    components/
      core_components.ex            #   Shared UI components
      layouts.ex                    #   App + root layouts
      layouts/
        root.html.heex              #   Root HTML shell
    live/
      home_live.ex                  #   Home page LiveView
    user_auth.ex                    #   Session auth plugs
    router.ex                       #   All routes + pipelines
    endpoint.ex                     #   HTTP entry point

config/
  config.exs                        # Shared config
  dev.exs                           # Dev DB, JWT secret, watchers
  test.exs                          # Test DB, JWT secret
  runtime.exs                       # Prod env vars (DB, JWT, secret_key_base)
  prod.exs                          # Prod compile-time config

priv/
  repo/migrations/                  # Ecto migrations
  static/                           # Static assets

test/
  awrad_api/                        # Context tests
  awrad_api_web/                    # Controller/LiveView tests
  support/                          # Test helpers, fixtures, conn_case
```
